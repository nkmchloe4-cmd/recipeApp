# Recipe App

En enkel responsiv webbapp för att bläddra bland recept byggd med React och Vite.


## Vad appen gör
- Visar en lista med recept
- Låter dig klicka på ett recept för att se detaljer (ingredienser och steg)


## Teknik
- React (Vite)
- JavaScript


## Komma igång
- Klona repot:
```bash
  git clone <din-repo-url>
```
- Gå in i projektmappen:
```bash
  cd recipeApp
```
- Installera beroenden och starta:
```bash
  npm install
  npm run dev
```

Öppna sedan http://localhost:5173 i webbläsaren.

## Struktur

* `src/components/` – återanvändbara komponenter
* `src/App.jsx` – huvudkomponenten
